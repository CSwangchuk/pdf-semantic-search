# PDF Semantic Search

A Python project that reads a PDF, splits it into chunks, creates sentence embeddings, and retrieves the most relevant sections for a natural-language query using cosine similarity.

## Tech Stack
- Python
- pypdf
- sentence-transformers
- scikit-learn

## How to run
```bash
python3 -m pip install pypdf sentence-transformers scikit-learn
python3 app.py
